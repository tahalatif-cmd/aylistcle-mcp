# Security

This repository holds documentation and manifests for the hosted AY Listicle MCP server. It contains no server code.

To report a security problem with the AY Listicle service or its MCP server (`https://www.aylistcle.com/api/mcp/mcp`), email team@aylistcle.com with "Security" in the subject. We reply within 2 business days.

Do not post secrets, tokens or personal data in public issues. Personal access tokens start with `ayl_`. If one leaks, revoke it in AY Listicle Settings, under AI assistants (MCP).
